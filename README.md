## Descrição

Projeto desenvolvido para praticar o uso do SQLAlchemy com Python e SQLite, trabalhando operações de conexão, criação de tabelas e consultas em bancos de dados.

## Conteúdos trabalhados

- Conexão com banco de dados;
- Modelos e criação de tabelas;
- Consultas básicas;
- Filtros;
- Verificação de existência;
- Ordenação e paginação;
- JOIN e OUTER JOIN;
- Agrupamentos;
- Funções de agregação;
- Campos calculados e projeções.

## Bancos de dados

- Loja Virtual: `loja_virtual.db`
- Escola: `escola.db`

Os bancos são criados localmente por meio dos scripts Python do projeto.

## Tecnologias utilizadas

- Python
- SQLAlchemy
- SQLite
